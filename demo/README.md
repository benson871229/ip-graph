# demo/ — 示範資料

給 `graph/ip-graph.html` 用的一組假資料,不需要真實環境的 log 就能看出工具在做什麼。

| 檔案 | 用途 |
|---|---|
| `demo.conn.log` | 一天的虛構醫院網段流量,Zeek `#fields` TSV 格式,489 筆 |
| `demo-assets.csv` | 對應的資產盤點表,18 筆 |
| `demo-threat.txt` | 對應的威脅情資,1 筆 |

## 怎麼用

1. 瀏覽器打開 `graph/ip-graph.html`
2. 拖入 `demo.conn.log`
3. 把 `demo-assets.csv` 與 `demo-threat.txt` 的內容分別貼進「資產盤點表」與「威脅情資」欄位
4. 聚焦 IP 填 `10.20.0.5`(影像伺服器),hop 拉到 2

會得到 32 個節點、68 條連線。

## 資料裡有什麼

| 類型 | 內容 |
|---|---|
| 影像 | CT / MRI / 超音波 → PACS,`104/DICOM`,全網最大流量 |
| 介接 | 生化分析儀 → LIS → HL7 引擎 → PACS,`2575` |
| 網域 | 工作站 → DC,`53/DNS`、`445/SMB`、`88/Kerberos` |
| 備份列印 | PACS → NAS `445`、PACS 與工作站 → 印表機 `9100` |
| 本地廣播 | LLMNR `224.0.0.252`、mDNS `224.0.0.251`、SSDP `239.255.255.250` |
| 正常對外 | Windows Update `443`、防毒更新 `8014` |
| ICMP | 工作站 → PACS,type 8 Echo Request |

## 刻意埋的三件事

**`10.20.0.88`** 不在資產表(紫色虛線圈),在存取 PACS 的影像、碰 DC 的 SMB、
對外傳了 3.2 億 bytes,而且掃了一小段 RDP(`10.20.0.150`–`157`,全部 `S0` 沒回應)。
它的外傳目的地 `203.0.113.47` 命中威脅情資(紅色發光)。

那三個多播位址會畫成**灰色**。它們是本地廣播,不是對外連線 ——
只判斷「是不是 RFC1918」的話會把它們誤標成公有 IP。

8 個 RDP 掃描目標各只有 120 bytes,想清掉就把「最小權重」拉高。

## 位址都是編的

這份資料不含任何真實環境資訊,全部用保留網段:

| 網段 | 依據 |
|---|---|
| `10.20.0.0/24` | RFC 1918 私有 |
| `198.51.100.0/24`、`203.0.113.0/24` | RFC 5737 文件專用 |
| `224.0.0.0/24`、`239.255.255.0/24` | 多播 |

沒有任何可路由的公有位址。
